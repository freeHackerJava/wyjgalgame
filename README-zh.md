# 周日编程班

> 合肥，2024 年秋。四个女孩，一条通往 NOI Au 的路。

## 关于游戏

《周日编程班》是一款以信息学竞赛为背景的叙事经营游戏。你扮演大三学生王怡钧，为了挣生活费接下了一份周日编程班的代课工作。

四个女孩——吴一鸣、刘子诺、朱皓辰、李佳迪——有着完全不同的性格与成长节奏。你要在每周有限的行动点里安排教学、辅导、谈心与模拟赛，帮助她们通过 CSP-S、NOIP、省队选拔，最终走向 NOI。

游戏的核心不是数值碾压，而是在长期相处中理解每个人害怕什么、需要什么，以及一个老师能陪伴学生走多远。

## 主要特色

- **叙事经营**：每周 3 点行动力，在“教科技、私下辅导、谈心、模拟赛、备课、复盘、散步”之间做选择。数值会衰减，心态会波动，没有一劳永逸的解法。
- **四位可攻略角色**：每个人都有自己的成长曲线、专属关系剧情与结局。好感度从陌生到心意相通，会逐步解锁更深入的对话。
- **多周目与记忆崩坏**：初次通关后，二周目开启“带着记忆重来”的叙事变体；三周目开始逐渐失去经营要素，转向纯叙事的记忆崩塌体验。
- **成就系统与全局进度**：成就跨存档累计，二周目解锁后永久保留，主菜单可查看汇总进度。

## 剧情结构

游戏按时间与里程碑推进：

- **序章**：初识四个女孩，定下“四个人都成为 NOI Au”的目标。
- **CSP-S / NOIP / 省队 / NOI**：四场关键比赛，每一关都有通过阈值与失败结局。
- **好感剧情**：每位角色在好感 4、8、10、12 时解锁专属场景，逐步深化关系。
- **二周目变体**：关键场景（序章、NOIP、省队前夜、NOI 前夜、NOI 结局）替换为“记忆正在错位”的版本。
- **三周目 / 四周目**：纯叙事，跟随王怡钧的记忆一路坍缩，直到被看见。

## 操作说明

### 主菜单

- **存档位**：共 3 个槽位，可随时开始、继续、覆盖或删除。
- **二周目**：在任意存档位完成 NOI 失败结局后解锁，主菜单会显示“二周目”按钮。
- **成就**：汇总所有存档已解锁的成就。
- **设置**：调整文字速度、自动播放停顿、跳过已读文本与全屏启动。

### 经营界面

- **行动点**：每周 3 点，用于安排教学与活动。
- **学生卡片**：显示水平、科技、好感、士气与稳定性；按钮对应四种单人行动。
- **集体行动**：备课（全员科技 +1）、集体复盘（全员水平 +2）、散步（全员士气+好感）、模拟赛（全员能力+士气浮动）。
- **结束本周**：推进时间，触发里程碑检查与随机事件。
- **好感剧情通知**：当某位学生好感达到阈值时，界面会出现提示，点击后进入专属剧情。

### 剧情播放

- **点击画面**：显示全文 / 推进到下一句。
- **底部工具栏**：下一句、跳过已读、快进到选项、自动播放、历史回看、保存进度、返回主菜单。
- **逐字动画**：速度可在设置中调整，0 为瞬间显示。
- **选项**：影响数值、好感度或后续剧情走向。

### 训练档案

在经营界面点击“训练档案”，可查看当前存档的：
- 训练概览（周数、里程碑、已解锁剧情数）
- 四位学生的详细数值与好感阶段
- 历次里程碑比赛与最近模拟赛成绩
- 已做出的关键选择
- 成就墙

## 存档与数据

存档保存在用户目录下：

- **Windows**：`C:\Users\用户名\.wyjgalgame\`
- **macOS / Linux**：`~/.wyjgalgame/`

文件说明：
- `save-0.json`、`save-1.json`、`save-2.json`：三个存档槽。
- `settings.json`：全局设置（文字速度、自动播放等）。
- `progress.json`：跨存档全局进度（二周目解锁状态、已继承的成就）。

## 开发技术栈

- **Kotlin + Compose Multiplatform**：桌面端 UI。
- **Voyager**：导航与屏幕管理。
- **kotlinx.serialization**：JSON 存档序列化。
- **纯 Kotlin 剧情引擎**：基于有向图的叙事系统，支持分支、选项与状态回溯。

## 剧情规模

- **核心主线**：序章 + 4 个里程碑 + 4 个失败结局 + 4 个正式结局。
- **好感剧情**：每位角色 4 段（好感 4/8/10/12），共 16 段。
- **二周目变体**：5 段关键场景替换。
- **三周目 / 四周目**：2 段纯叙事长线。
- **随机事件**：约 20 种，分散在经营过程中触发。
- **总计对白节点**：超过 600 个。

## 关于“多周目”叙事

游戏设计了四层周目结构，不是为了重复刷数值，而是为了讲述同一个故事在不同“记忆状态”下的不同样貌：

- **一周目**：正常教学体验，经营与叙事并重。
- **二周目**：王怡钧带着一周目的记忆重来，但记忆开始错位。经营界面精简，关键场景替换为“记忆崩坏”变体，结局停在 NOI 的崩塌。
- **三周目**：纯叙事。经营界面消失，王怡钧的记忆持续溃散，竞赛从 50% 存在感衰减到 20%。
- **四周目**：从吴一鸣的视角重新走进那间教室，用身体记忆拼合碎片。

## 常见问题

**Q：为什么二周目经营界面变精简了？**  
A：二周目的重点已经从“怎么教”转向“记忆正在崩坏”。经营仍存在，但行动被压缩为两种集体行动 + 结束本周，数值衰减刻意大于收益，让玩家感受“怎么补都补不上”的无力感。

**Q：四周目怎么解锁？**  
A：完成三周目后，在二周目或四周目结局面板的角落会出现“我看见你了”入口。

**Q：好感剧情错过了还能补吗？**  
A：好感达标后，经营界面会出现“进入好感剧情”按钮，可以主动触发。如果当时选择跳过，剧情会暂存，下次进入经营界面仍可触发。

**Q：成就跨存档继承吗？**  
A：是的。所有已解锁的成就 id 会汇总到全局进度中，主菜单的成就总览会显示所有存档的并集。
